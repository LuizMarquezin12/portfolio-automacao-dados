# Como avaliar e contribuir

Cada case é independente. Leia o README da respectiva pasta antes de executar exemplos.

1. Use um ambiente virtual Python isolado.
2. Instale somente as dependências declaradas pelo projeto.
3. Use dados sintéticos e ambientes autorizados.
4. Verifique os arquivos gerados antes de compartilhá-los.
5. Documente entradas, saídas, erros e limitações.

Boas contribuições incluem testes, documentação, melhoria de logs e exemplos reproduzíveis que não revelem informações privadas ou corporativas.
