# Portfólio — Automação, Dados e Melhoria de Processos

Portfólio técnico de **Luiz Henrique Garcia**, reunindo projetos demonstrativos de automação de processos, RPA, tratamento de dados e eficiência operacional.

> **Confidencialidade:** os projetos deste portfólio são versões demonstrativas e sanitizadas. Não são publicados dados de clientes, credenciais, URLs internas, bases corporativas ou outras informações confidenciais.

## Competências

**Python · RPA · Selenium · Playwright · PyAutoGUI · pandas · openpyxl · DuckDB · Power BI · Power Query · Excel · Automação de Processos · Melhoria de Processos · Dados**

## Projetos

### 1. Gerador e Validador de Listas de Rateio
Pipeline para leitura de máscaras Excel, normalização, enriquecimento de dados, validação de campos obrigatórios e geração de arquivos por distribuidora.

### 2. Pipeline de Captura de Faturas
Arquitetura demonstrativa de RPA para consultas web, captura e organização de documentos e acompanhamento do processamento.

### 3. Pipeline de Dados para Power BI
Tratamento e consolidação de bases de múltiplas competências, classificação de registros e preparação de indicadores.

### 4. Processamento de Demonstrativos
Leitura, normalização e cruzamento de demonstrativos com bases faturáveis para identificação de atendimentos e pendências.

### 5. Automação de Excel e Qualidade de Dados
Rotinas para padronização de colunas, deduplicação, validação, cruzamento e geração de relatórios.

## Sobre

Projetos desenvolvidos para demonstrar experiência prática em **automação, melhoria de processos, RPA e dados**, com foco em redução de tarefas manuais, confiabilidade e escalabilidade operacional.
