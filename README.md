Portfólio técnico com **cases demonstrativos inspirados em desafios reais de operação**, mostrando como automação e dados podem reduzir trabalho manual e melhorar a rastreabilidade. Os exemplos devem usar exclusivamente dados sintéticos e código autorizado para publicação.

| Projeto | Competências demonstradas | Documentação |

## Impacto observado

- Capacidade de **300–400 faturas/dia** em determinados fluxos de automação.
- Caso de aproximadamente **1.150 consultas em 2h10**.
- Consolidação de dezenas de milhares de registros para acompanhamento operacional.
- Redução de atividades manuais e da dependência de captura terceirizada.

> Esses números são observações de cenários específicos, **não benchmarks reproduzíveis** dos exemplos públicos. Valores financeiros e informações corporativas não são divulgados.
