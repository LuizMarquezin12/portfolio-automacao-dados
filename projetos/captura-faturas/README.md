# Pipeline de Captura de Faturas

Projeto demonstrativo de automação de consultas e organização de documentos.

## Recursos
- leitura de uma fila de consultas;
- automação de navegação;
- registro de sucesso, pendência e erro;
- organização de documentos por referência;
- retomada de processamento;
- geração de logs operacionais.

## Tecnologias
Python · Selenium · Playwright · PyAutoGUI · pandas

O repositório não inclui credenciais, portais privados, dados de clientes ou mecanismos destinados a contornar controles de acesso.
