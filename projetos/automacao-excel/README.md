# Automação de Excel e Qualidade de Dados

Conjunto conceitual de rotinas reutilizáveis para operações com planilhas.

## Exemplos
- normalização de nomes de colunas;
- limpeza de documentos e identificadores;
- conversão CSV/XLSX;
- deduplicação;
- validação de campos;
- joins entre bases;
- geração automatizada de relatórios.

## Tecnologias
Python · pandas · openpyxl · DuckDB
