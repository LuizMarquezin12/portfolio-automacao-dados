# Pipeline de Dados para Power BI

Pipeline para preparar bases operacionais utilizadas em indicadores.

## Etapas
- leitura de múltiplas competências;
- padronização de distribuidoras e identificadores;
- cruzamento de bases;
- deduplicação;
- classificação de registros atendidos e pendentes;
- consolidação da base analítica;
- preparação para consumo pelo Power BI.

## Tecnologias
Python · pandas · Excel · Power Query · Power BI
