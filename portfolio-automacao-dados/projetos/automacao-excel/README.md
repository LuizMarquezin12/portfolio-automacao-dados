# 🧹 Case — Excel, De/Para e Qualidade de Dados

## 🔴 Problema
Bases operacionais vindas de fontes diferentes frequentemente possuem nomes de colunas, formatos, identificadores e duplicidades incompatíveis.

## 🟢 Solução
Criação de rotinas reutilizáveis para:
- normalização de colunas;
- limpeza de UCs, contratos e documentos;
- De/Para de UCs antigas e novas;
- deduplicação;
- cruzamento entre bases;
- validação de obrigatórios;
- tratamento de CSV/XLSX/JSON;
- geração de arquivos e relatórios.

Também foram desenvolvidas rotinas auxiliares para geração/organização de PDFs, livros, índices e controles operacionais.

## 🎯 Resultado
Bases mais consistentes para alimentar automações, rateio e indicadores, reduzindo ajustes manuais entre etapas.

## 🛠 Stack
Python · pandas · openpyxl · DuckDB · Excel
