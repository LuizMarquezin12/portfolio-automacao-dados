# Segurança e confidencialidade

Este é um portfólio demonstrativo. Antes de publicar qualquer alteração:

- Não incluir credenciais, tokens, cookies, sessões ou chaves de API.
- Não publicar CPF/CNPJ, UCs, contratos, faturas ou dados reais de clientes.
- Não incluir endpoints privados, caminhos internos, código proprietário, máscaras corporativas ou regras confidenciais.
- Não publicar técnicas para contornar CAPTCHA, WAF, autenticação ou controles de acesso.
- Revisar o diff, os metadados dos arquivos e o histórico de commits.
- Confirmar autorização para publicar qualquer código derivado de trabalho corporativo.

**Atenção:** `.gitignore` não protege arquivos já rastreados e não remove segredos do histórico. Se houver exposição, revogue as credenciais e trate o histórico adequadamente.

Para comunicar um problema sensível, utilize um canal privado em vez de abrir uma issue pública com os dados.
